# Jadhav Tech Solutions — Website

A responsive static website built with HTML, CSS and vanilla JavaScript for GitHub Pages.

## Files
- `index.html` — homepage, responsive styles, service sections, contact email-draft form, and rule-based demo chatbot.
- `logo.png` — existing business logo.
- `CNAME` — custom domain mapping for `jadhavtechsolutions.com`.

## Preview locally
Open `index.html` in a modern browser. No build step or package manager is required.

## Important implementation notes
- The chatbot is a rule-based frontend demo. It does not use an AI model or store messages.
- The contact form opens a prefilled `mailto:` draft. It does not submit data to a server. Connect a secure form endpoint/CRM before relying on it for production lead capture.
- Verify the listed contact details before publishing.
- Only publish support hours, staffing claims, client names, testimonials and certifications that can be substantiated and that you have permission to use.

## Publish
Commit the reviewed files to the GitHub Pages publishing branch after testing. Keep `CNAME` and `logo.png` in the published root.
